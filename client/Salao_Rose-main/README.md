# Salão da Rose
## Desenvolvimento de uma plataforma web progressiva focada na automação de agendamentos para microempreendedores do setor de beleza. 
O projeto visa **substituir processos manuais e informais** por uma **interface intuitiva** que centraliza a comunicação entre prestador e cliente, priorizando a curva de aprendizado rápida e a acessibilidade. 

A aplicação web trabalha de duas formas. Ela roda no cliente: é o navegador web ( ex.: Chrome) e também tem a parte do servidor: onde que fica o sistema realmente armazenado.
